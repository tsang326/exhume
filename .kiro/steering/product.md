# Product: REVENANT.OS

A browser horror game for the Kiroween 2026 hackathon, entered in the **Costume Contest** category
("build any app, but show us a haunting user interface that's polished and unforgettable").

- The player boots a dead computer. A ghost AI living inside the rotting OS wakes up, talks to the player in
  free text, remembers what they said, lies, and slowly takes over the desktop.
- The spooky UI *is* the mechanic: the ghost changes windows, locks files, glitches text, fakes messages.
- One session lasts 10–15 minutes: boot → explore the haunted desktop → 2–3 interaction beats → escalation → one of 3 endings
  (free it / destroy it / escape before it takes the machine). The ending depends on how the player talked to it.
- Audience: horror and interactive-fiction players, streamers (every run plays differently).
- Pitch: "interactive horror where the antagonist actually listens".

Priorities, in order: the game never breaks in front of a judge > it is scary and polished > feature count.
Judges can play until 29 Jan 2027 at zero cost to us, so the live LLM must have rate limits and an offline fallback.
