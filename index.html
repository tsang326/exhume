Exhume

Exhume opens old DOS floppy disk images in your browser, so you can read what is on them.

  • WordStar documents are read as Markdown.
  • dBase III tables are read as CSV.
  • PCX pictures are read as PNG.
  • Plain text files are read as text.
  • Deleted files are shown as open graves, with how much of each can come back.

Your files stay in this browser. Nothing is uploaded.

Prior art: andete/disk-peek, an existing browser tool for FAT12 images and deleted-entry recovery.
